Deep dive // 01

Workflows you can read like a sentence.

Every automation we ship is declarative and versioned. No black-box drag-and-drop — your team can see exactly what triggers, what runs, and what happens on failure.

  • Trigger on schedule, webhook or queue event
  • Built-in retries, alerting and audit trail
  • Deploys through CI — fully reproducible
invoice_sync.ops.ts
1// reconcile vendor invoices nightly
2export const invoiceSync = workflow({
3  trigger: schedule("0 2 * * *"),
4  retries: 3,
5  run: async ({ step }) => {
6    const rows = await step.fetch("erp.invoices");
7    const matched = reconcile(rows, ledger);
8    await step.commit(matched);
9    return { synced: matched.length };
10  },
11});
Deep dive // 02

Integrations that don't break at 2am.

We define explicit contracts between your systems, so a field rename in one tool never silently corrupts another. Typed, validated, observable.

  • Schema-validated payloads on every hop
  • Dead-letter handling for bad records
  • Live health metrics per connection
integration.config.yaml
1source: crm.deals
2target: warehouse.revenue
3mode: stream
4contract:
5  deal_id: string !
6  amount: number !
7  closed_at: timestamp
8on_error: dead_letter
9alerts:
10  channel: "#ops-alerts"
11  threshold: 0.99
